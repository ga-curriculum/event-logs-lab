## About

You'll get hands-on practice working with key system logs in this lab.

The goal of the lab is to gain experience navigating and analyzing the event logs for your operating system. You'll learn where to access key logs, how to filter log entries to find relevant information, and practice identifying potential issues in the logs.

Building skill in interpreting these native logs is valuable for troubleshooting and monitoring the health of your systems.
