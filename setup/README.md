## Setup

Open your Terminal application and navigate to your <code class="filepath">~/code/ga/labs</code> directory:

```bash
cd ~/code/ga/labs
```

### Create and clone a GitHub repo

Make a new repository on [GitHub](https://github.com/) named `event-logs-lab`.

Clone a copy of your remote repo locally by using the `git clone` command:

```bash
git clone https://github.com/<your-username>/event-logs-lab.git
```

Replace `<your-username>` (including the `<` and `>`) with your GitHub username before you run this command.

### Launch in VS Code

Next, `cd` into the cloned directory, <code class="filepath">event-logs-lab</code>:

```bash
cd event-logs-lab
```

Create a <code class="filepath">README.md</code> file in this directory:

```bash
touch README.md
```

Open the contents of the directory in VS Code:

```bash
code .
```

Open the <code class="filepath">README.md</code> file in VS Code and add the following content to it:

```markdown
# Event Log Lab

## Operating system



## Screen capture of your operating system's event viewer



## Reflection



```

Add the name of your operating system (for example, Windows 11, macOS Sequoia, or Ubuntu 24.04) to the **Operating System** section.
